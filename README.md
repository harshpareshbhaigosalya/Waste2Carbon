## 📌 Problem Statement & Core Thesis

Across agricultural economies (particularly in India's agrarian belts), over **90 million tons of crop stubble (parali)** are openly burned annually. This releases hazardous particulate matter ($PM_{2.5}$, $PM_{10}$), carbon monoxide, and greenhouse gases into the atmosphere, causing catastrophic seasonal smog and soil fertility degradation.

### Why Existing Approaches Fail:
1. **The Fragmented Logistics Chasm**: Industrial plants (Biochar pyrolysis and Compressed Bio-Gas / CBG digesters) cannot dispatch 15-ton trucks to collect 1–2 tons from individual smallholders—diesel travel costs exceed the feedstock's commercial value.
2. **Quality & Moisture Distrust**: Buyers fear paying for wet or contaminant-laden biomass, while farmers lack a transparent mechanism to defend their sun-dried, baled material.
3. **No Direct Carbon Incentive for Farmers**: High-overhead carbon registries leave smallholders completely detached from voluntary carbon credit revenue.
4. **Digital Divide & Literacy Barriers**: Rural farmers struggle with complex digital SaaS workflows.

## 💡 The Waste2Carbon Solution

**Waste2Carbon** bridges the gap between rural biomass producers and industrial bio-refineries through a 6-pillar system:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                 WASTE2CARBON PLATFORM                                  │
├──────────────────────┬────────────────────────┬────────────────────────────────────────┤
│ 📸 Vision Inspection │ 💬 Two-Way Negotiation │ 🧠 Autonomous Voice AI                │
│ Live in-app camera   │ Interactive pricing    │ Groq LLaMA 3.3 multilingual            │
│ & moisture grading   │ counter-offers & chat  │ agent executing live DB actions        │
├──────────────────────┼────────────────────────┼────────────────────────────────────────┤
│ 📍 Village Clusters  │ 🤝 Handshake OTP       │ 📜 Immutable MRV Ledger                │
│ GIS-driven payload   │ Zero-trust physical    │ IPCC-compliant dual-party carbon       │
│ & TSP route dispatch │ weighbridge handover   │ credits & printable certificates       │
└──────────────────────┴────────────────────────┴────────────────────────────────────────┘
```

1. **In-App Camera Quality Inspection**: Native smartphone camera trigger and live browser webcam capture with automatic client-side compression. Waste is classified into **Grade A (<12% moisture)**, **Grade B (12–20%)**, or **Grade C (>20% moisture)**.
2. **Interactive Two-Way Negotiation Engine**: Processors can counter-bid lower prices with photo justification (e.g. factoring moisture drying costs), while producers can defend pricing or negotiate counter-rates in an interactive thread with quick-adjust chips (`-₹200 Moisture`, `+₹200 Pure`).
3. **Smart Village Aggregation & Route Optimization**: Aggregates nearby farm listings within a dynamic radius into consolidated truckloads (e.g. 10.0 Tons), calculating round-trip distance, diesel savings, and Traveling Salesperson (TSP) doorstep waypoint sequences.
4. **Agentic Voice Intelligence (Groq Cloud LLaMA 3.3 70B)**: Rural users can speak naturally in **Hindi, Hinglish, Punjabi, or English** (e.g., *"Mere paas 10 ton parali hai, biochar plant ko becho"*). The autonomous agent extracts intent and directly performs database actions (creates listings, submits bids, queries ledger).
5. **Secure Cryptographic OTP Handshake**: A 6-digit dynamic OTP is verified upon physical truck arrival alongside certified weighbridge receipts to eliminate ghost deliveries.
6. **National IPCC MRV Sequestration Ledger**: Computes permanent $tCO_2e$ removal and issues dual-party certified carbon credits ($1\text{ credit} = 1\text{ metric ton } CO_2e$) with downloadable and printable official environmental certificates.

     │                   │                    │                   │                │             │             │

 grade rating       village hubs         date locked         sequence          & enters OTP  conversion    certificates

## 🧮 IPCC Carbon Sequestration Formulas

Waste2Carbon implements empirical carbon accounting standardizing **IPCC Tier-2 Waste Guidelines** and the **European Biochar Certificate (EBC)**:

### 1. Dry Agricultural Stubble $\to$ Biochar Pyrolysis
$$\text{Avoided Open Burning Emissions} = 0.48 \, tCO_2e / \text{ton}$$
$$\text{Stable Biochar Carbon Fixation} = 0.82 \times \left(\frac{\text{Dry Matter Ratio}}{0.7}\right) \, tCO_2e / \text{ton}$$
$$\text{Total Net Removal} = \text{Avoided Emissions} + \text{Stable Fixed Carbon}$$

*1 ton of dry crop residue converted via pyrolysis yields $\approx 1.16\text{ to } 1.30 \, tCO_2e$ permanently sequestered for $>100\text{ years}$.*

### 2. Wet Organic Waste $\to$ Anaerobic Biogas Digester
$$\text{Fugitive Methane Avoidance} = 1.28 \, tCO_2e / \text{ton}$$
$$\text{Fossil Fuel (LPG/Diesel) Displacement} = 0.38 \, tCO_2e / \text{ton}$$
$$\text{Total Net Avoidance} = 1.66 \, tCO_2e / \text{ton}$$

## 🚀 Getting Started Locally

### Prerequisites
- **Node.js** (v18.0.0 or higher)
- **npm** (v9.0.0 or higher)
- Free account on [Supabase](https://supabase.com)
- Free API key on [Groq Cloud](https://console.groq.com)

### 1. Clone the Repository
```bash
git clone https://github.com/harshpareshbhaigosalya/Waste2Carbon.git
cd Waste2Carbon
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Supabase Backend
1. Create a new Supabase project.
2. In the Supabase Dashboard, open the **SQL Editor**.
3. Copy and run the entire SQL script from [`supabase_schema.sql`](supabase_schema.sql).
4. Create a `.env` file in the root directory:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```

### 4. Start Development Server
```bash
npm run dev
```
Visit `http://localhost:5173` to explore Waste2Carbon.

### 5. Build for Production
```bash
npm run build
```

## ⚡ Killer Differentiators vs. Traditional Solutions

1. **Integrated WhatsApp Goods Receipt Note (GRN)**:
   - Eliminates paperwork in rural mandis. Once the 6-digit OTP is validated at the weighbridge, both farmer and plant receive automated dispatch receipts with direct **1-click WhatsApp sharing** (`wa.me/?text=...`) containing weights, settlement payouts, and certificate hashes.

2. **Autonomous Voice AI in Indian Vernaculars**:
   - Powered by **Groq LLaMA 3.3 70B** with real-time browser speech recognition, allowing lay farmers to list biomass, check market rates, and accept bids entirely by speaking in Hindi, Gujarati, Punjabi, or English.

3. **Persistent Session Management**:
   - Zero-interruption refresh recovery caching user sessions in client state while continuously validating against Supabase Auth & PostgreSQL profiles.
